# Reproducibility map

This document records the complete mathematical configuration and the
release-facing result summary. The repository is a compact public snapshot: it
contains the accepted numerical tables and figure inputs, while the manuscript
source, compiled manuscript, and complete historical 361 MiB result tree are
not included. Historical formal manifests remain authoritative for the exact
source snapshots used by those runs.

## Common mathematical configuration

- dimension: `d=2`;
- measure: standard Gaussian;
- operator: `A = -Delta + x dot grad + I`;
- activation: fourth-order RePU, `(t)_+^4`;
- fixed numerical radius: `R=5.5`;
- bias interval: `[-5,5]`, shifted by `3/4` of one bias mesh step;
- residual quadrature: rotated Cartesian cells, three Gauss--Legendre nodes
  per coordinate and positive weights multiplied by the Gaussian density;
- error quadrature: tensor composite Gauss--Legendre with four nodes per
  coordinate and Gaussian density.

## Numerical experiments

### Convergence

```text
(n_dir,n_bias,J,N) =
(20,21,420,1680), (24,25,600,2380), (32,33,1056,4128),
(40,41,1640,6392), (48,49,2352,9120), (56,57,3192,12320).
```

The four smooth manufactured solutions use coefficient radius `M=1`; the
limited-regularity solution uses `M=2000`.  The stored least-squares
representatives satisfy the respective radii.

The six measured fill distances on the fixed parameter domain are
`0.514222, 0.430900, 0.325448, 0.261467, 0.218511, 0.187679`. Unweighted
six-point fits of `log(E_s)=log(C)+p*log(h_Theta0)` give the following slopes:

| Solutions | `E0` | `E1` | `E2` | `E3` |
|---|---:|---:|---:|---:|
| four smooth solutions, range | 3.08--3.33 | 2.92--3.18 | 3.02--3.14 | 2.26--2.47 |
| limited-regularity `u5` | 2.42 | 2.53 | 2.68 | 2.31 |

These are finite-resolution fits on a fixed parameter window, not a numerical
proof of the theorem's asymptotic rate or logarithmic factors.

### Quasi-uniform versus random parameters

All designs use `J=600`, `N=2380`, and the same residual point set generated by
the `24 x 25` quasi-uniform reference design.  Random-direction and fully iid
designs use seeds `0,...,49`.

For every random parameter set the four smooth-solution errors are first
averaged; the table then reports the mean and sample standard deviation over
50 parameter sets:

| Design | `E0` | `E1` | `E2` | `E3` |
|---|---:|---:|---:|---:|
| quasi-uniform | `7.774e-7` | `2.361e-6` | `8.534e-6` | `8.700e-5` |
| random directions | `(1.869+/-1.735)e-6` | `(6.383+/-6.159)e-6` | `(2.866+/-2.215)e-5` | `(3.067+/-1.927)e-4` |
| iid parameters | `(2.494+/-0.648)e-6` | `(8.586+/-1.964)e-6` | `(4.402+/-0.819)e-5` | `(4.342+/-0.715)e-4` |

The corresponding `(fill distance, antipodal separation)` values are
`(0.431,0.2000)` for the quasi-uniform set,
`(0.780+/-0.110,(9.05+/-8.47)e-3)` for random directions, and
`(0.734+/-0.080,(9.13+/-4.63)e-3)` for iid parameters.

### Coefficient radius

```text
J=272, N=624, H=0.6444, eta=1e-4,
mu in {1/32,1/16,1/8,1/4,1/2,3/4,1,3/2,2},
20 weighted-unit Gaussian perturbations with seeds 20,...,39.
```

The unperturbed minima over the tested grid occur at
`mu=(3/4,1/2,1/4,1/4)` for `u1,...,u4`, with direct `E3` equal to
`(5.91e-4,4.25e-4,1.80e-4,7.35e-5)`. The perturbed mean minima occur at
`mu=(1/2,1/2,1/4,1/8)`, with mean plus/minus one sample standard deviation
`(1.11+/-0.04)e-3`, `(8.95+/-0.88)e-4`, `(8.96+/-0.74)e-4`, and
`(5.57+/-0.29)e-4`.

### Residual-point count

With `J=272`, use

```text
N = 112, 276, 624, 1108, 1708, 2480
N/J = 0.412, 1.015, 2.294, 4.074, 6.279, 9.118.
```

Ranks are computed from the column-normalized weighted residual matrix using
the relative cutoffs `max(N,J)*eps`, `1e-12`, and `1e-14`. At the machine
cutoff the first two ranks are 112 and 266; all three cutoffs give rank 272 at
`N/J=2.294`. The smallest column singular value then increases from
`2.85e-17` to `2.05e-7` and remains between `2.05e-7` and `2.98e-7` on the
three larger grids. These are finite-matrix rank and condition diagnostics,
not the function-space stability constant in the theorem.

### Same-direction and antipodal collisions

For the same-direction study, six fourth-order RePU atoms share direction
`a=(1,0)` and have biases `(ell-5/2)*delta`, `ell=0,...,5`, with
`delta=2^(-j)`, `j=3,...,7`. The fitted inverse-constant exponents for
Sobolev orders 1 through 4 are `0.9232,1.9106,2.9069,3.9056`; the explicit
fifth-difference vector gives `0.9984,1.9982,2.9976,3.9976`. All fits have
`R^2>0.999`; closed Gaussian moments were evaluated at 100 decimal digits and
rechecked at 140 digits.

For the antipodal study, fix `N=4112`. With `J=132`, reducing antipodal
separation from `4.55e-1` to `9.09e-6` changes the smallest singular value from
`1.53e-6` to `1.95e-11` and the cutoff condition number from `2.79e6` to
`2.23e11`. At exact collision the computed ranks are 81 for `J=132` and 543
for `J=1056`, matching the algebraic upper bounds `P+15`; the dimension loss
itself follows from the exact RePU identity, not from floating-point ranks.

### Integration-domain audits

With the fitted coefficients fixed, the error integrals were recomputed on
`[-L,L]^2`, `L=8,9,10`, using cell width `0.05` and the same order-four tensor
rule.  The largest adjacent relative changes were:

| Cohort | `8 -> 9` | `9 -> 10` |
|---|---:|---:|
| six-level convergence | `8.48e-4` | `2.01e-6` |
| 101 parameter designs | `2.59e-4` | `4.11e-7` |
| unperturbed coefficient-radius `E3` | `2.23e-8` | `1.85e-11` |
| perturbed-mean coefficient-radius `E3` | `9.22e-10` | `5.36e-13` |

## Released verification commands

Rebuild all four publication PNGs solely from released inputs and compare their
SHA-256 digests with the fixed release digests:

```bash
make test
```

Write a retained regenerated copy to `build/figures/` with:

```bash
make figures
```

The compact tables in `data/paper/` are the public numerical evidence. The
historical formal runners and full artifacts are intentionally outside this
release because several depended on unpublished working directories and exact
source snapshots. This repository therefore verifies the released
data--figure chain without claiming to rerun those historical artifacts or to
distribute the manuscript source.
