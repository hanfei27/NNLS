# Gaussian--Hermite least squares with frozen RePU networks

This repository is the compact companion artifact for the manuscript

> **Gaussian--Hermite inverse inequalities, optimal Sobolev approximation,
> and full-space PDE least squares for frozen shallow RePU networks**

It contains the numerical tables used by the paper and the code needed to
regenerate four publication figures. The manuscript source, bibliography,
compiled manuscript, historical development tree, and full formal-run
artifacts are deliberately excluded.

## Repository layout

```text
.
├── code/
│   ├── plot_moc_publication_figures.py
│   ├── plot_moc_noisy_fullrank_l1_small_mu_extension.py
│   ├── reproduce_paper_figures.py
│   └── tests/test_reproduce_paper_figures.py
├── data/
│   └── paper/                 # compact accepted tables and provenance
├── docs/REPRODUCIBILITY.md    # complete configurations and reported results
└── requirements.txt
```

## Environment

The released figures were generated with Python 3.13.13 and the pinned
packages in `requirements.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Verify the release

```bash
make test
```

The test rebuilds all four figures in a temporary directory and checks their
SHA-256 digests against the fixed release digests.

To keep a regenerated copy, run

```bash
make figures
```

The output is written to `build/figures/`. Remove that directory before
running the command again; the generator rejects an existing destination.

## Reproducibility boundary

`data/paper/` is a compact export of the accepted numerical evidence. It
contains the rows used by the four figures and the additional tables and
acceptance summaries needed to inspect the numerical statements in the
manuscript. The coefficient-radius figure uses a 36-row summary with the
unperturbed error, perturbed mean, and one-sample-standard-deviation band for
each solution and radius.

The complete historical result tree was approximately 361 MiB and included
solver diagnostics, coefficient arrays, duplicate CSV/JSON representations,
and development-only runners. It is not part of this compact release. The
original artifact-manifest hashes and the precise aggregation rule are
recorded in `data/paper/l1_publication_provenance.json`.

Accordingly, this repository supports two claims:

1. the reported configurations and numerical values can be inspected;
2. the four manuscript figures can be regenerated byte-for-byte from the
   released tables.

It does not claim to reconstruct every historical formal artifact from
scratch. The full configurations and result summaries are listed in
[`docs/REPRODUCIBILITY.md`](docs/REPRODUCIBILITY.md).

The manuscript source, bibliography, and compiled manuscript are not part of
this repository.
